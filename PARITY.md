# OoT Randomizer parity

The goal is that every OoT Randomizer setting and location type works in the remake. The one exception is glitch
logic, because the remake's geometry is different. Tricks stay off by default and I verify them one by one. This file
is generated by `tools/rando/parity_report.py` from OoTR's SettingsList and the code, so don't edit it by hand.
